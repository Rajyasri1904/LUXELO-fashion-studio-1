# 👗 LUXELO – Fashion Studio

A modern, responsive e-commerce fashion storefront built with **HTML5**, **CSS3**, and **Vanilla JavaScript** as a B.Tech mini web development project. Designed with a luxury editorial aesthetic featuring a cream, warm beige, blush pink, and obsidian black palette.

---

## ✨ Key Features

- **Responsive Editorial Navigation:** Sticky glassmorphic header with mobile menu drawer, smooth anchor scrolling, and a live shopping cart badge.
- **Hero Showcase:** Full-width editorial banner featuring *"STYLE THAT DEFINES YOU"* headline, brand story, and quick-shop CTA.
- **Shop by Category:** Interactive visual cards for **Women**, **Men**, **Kids**, and **Accessories** with smooth hover zoom transitions.
- **Interactive Featured Collections:** Tab-based filtering across **All**, **New Arrivals**, **Trending**, and **Best Sellers**.
- **Product Grid & Cart Functionality:** 8 curated product cards displaying ratings, original vs. discounted pricing in Indian Rupees (`₹`), wishlist toggle, and interactive **Add to Cart** drawer with toast notifications.
- **Seasonal Sale Banner:** Dedicated promotional section highlighting up to **50% OFF** with promo code `LUXELO50`.
- **Newsletter & Studio Footer:** Email subscription form with instant feedback and a structured 4-column studio footer.
- **Mobile-First Responsive Design:** Built using CSS Grid and Flexbox to adapt seamlessly across desktop, tablet, and mobile screens.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic structure (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Custom properties (`:root` color variables), CSS Grid, Flexbox, keyframe animations, and media queries
- **Google Fonts:** *Playfair Display* (Editorial Headings) & *Poppins* (Clean UI & Body Text)
- **JavaScript (ES6):** Interactive category tabs, shopping cart drawer state, and toast notifications
